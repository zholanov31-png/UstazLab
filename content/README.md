# content/ — педагогикалық мазмұн (кодтан бөлек)

Бұл папкада платформаның **мазмұны** тұрады: әдістер, теория, сабақ үлгілері, жағдаяттар, тапсырмалар.
Код (`src/`) мазмұнды осы жерден оқиды, бірақ мазмұн кодқа тәуелді емес. Сондықтан бұл файлдарды
кейін басқа жобаға (бизнес нұсқасына) көшіруге болады: React, Supabase немесе осы сайттың баптауларын білу қажет емес.

## Құрылымы

```
content/
  README.md                  ← осы файл: ережелер және құқықтар тізілімі
  stations/
    04-gamification.json     ← 4-станция: Геймификация (дайын)
    02-case-study.json       ← келесі (әлі жоқ)
    ...
```

## Станция файлының форматы (`schema: "ustazlab-station/1"`)

| Өріс | Не | Бизнеске көшеді ме |
|---|---|---|
| `slug`, `method`, `title`, `desc`, `duration`, `goals` | Станция туралы жалпы мәлімет | иә |
| `theory[]` | Теория бөлімдері: `title`, `body[]`, `list`, `table`, `note`, `sources[]` | иә |
| `example` | Сабақ үлгісі: мақсат, сюжет, кезеңдер, бағалау | иә |
| `scenarios[]` | Педагогикалық жағдаяттар: `options[]`, `best`, `feedback` | иә |
| `task` | Практикалық тапсырма және оның өрістері | иә |
| `reflection` | Рефлексия сұрағы | иә |
| `rights` | Авторлар, негіз, коммерциялық қолдану шарты | иә (міндетті түрде бірге) |

**Бұл файлдарда ЖОҚ (диссертация платформасына ғана тиесілі, `src/data/modules.js`-те):**
`id`, `ready`, `competencies` (диссертацияның 5 құзыреті), `badge`, XP ережелері.

## Бизнес нұсқасына ЕШҚАШАН көшпейтіндер

- `src/data/assessment.js` — диссертацияның өлшеу құралы (кіріс/шығыс диагностика).
- Supabase-тегі барлық деректер: студенттердің жауаптары, тапсырмалары, рефлексиялары, профильдері.
  Олар зерттеуге келісіммен жиналған жеке деректер, коммерциялық мақсатқа қолдануға болмайды.
- Студенттердің сабақ жобалары — тек авторының **бизнеске арналған жеке** жазбаша келісімі болса
  (диссертацияға жариялау келісімі бизнеске жарамайды).

## Ережелер

1. Мазмұнға университет атауы, логотипі немесе оның ресурстарына сілтеме жазылмайды
   (университет атауы тек платформа қабығында: `src/pages/Landing.jsx` төменгі жолы).
2. Әр файлда `rights` блогы болуы керек. Авторы белгісіз немесе басқа сайттан алынған мазмұн қойылмайды.
3. Басқа авторлардың ойлары тек мазмұндама түрінде, `sources` сілтемесімен беріледі (көшірме емес).
4. Тарихи фактілер интернеттен тексеріледі (CLAUDE.md, 4-ереже).

## Құқықтар тізілімі

| Мазмұн | Авторлар | Коммерциялық қолдану шарты |
|---|---|---|
| `stations/04-gamification.json` (теория, квест-сабақ) | Жоланов Ө.К., Сугирбаева Г.Д. (мақала негізінде) | Тең автордың (Сугирбаева Г.Д.) жазбаша келісімі |
| Платформаның сәндік суреттері (`public/img/`) | Canva AI арқылы жасалған | Canva-ның сол кездегі лицензия шарттарын тексеру |
| `src/data/content.js` (кітапхана: квесттер, кейстер, деректер) | Gemini нұсқасынан қалған, авторлығы мен фактілері тексерілмеген | Тексерілгенге дейін көшірілмейді |
