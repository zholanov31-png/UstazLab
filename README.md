# UstazLab 2.0

Болашақ тарих мұғалімдерінің кәсіби құзыреттілігін дамытуға және оны өлшеуге арналған платформа.

## Не өзгерді (1.0 нұсқамен салыстырғанда)

- Нақты тіркелу мен кіру (Supabase Auth). Жалған Google/Apple/Facebook батырмалары алынып тасталды.
- Барлық нәтиже базада сақталады: бетті жаңартсаңыз да жоғалмайды.
- **Кіріс → курс → шығыс** логикасы. Құзырет тек диагностика арқылы өлшенеді, «+X%» енді нақты pre/post айырмасы.
- Рефлексиялар базаға жазылады.
- Зерттеуші бетінде: топ бойынша сүзгі, pre/post статистикасы (t, Cohen dz), Excel/SPSS-ке CSV экспорт.
- Код 1 файлдан бөлек беттерге (`src/pages`) және мазмұн файлдарына (`src/data`) бөлінді.
- Тексерілмеген фактілер мен әдебиеттер белгіленді. Белгіні тек зерттеуші көреді.

## Іске қосу (бір рет)

### 1. Supabase
1. supabase.com → жобаңызды ашыңыз → **SQL Editor** → **New query**.
2. `supabase/schema.sql` файлының мазмұнын толық көшіріп қойып, **Run** басыңыз.
3. **Project Settings → API** бетінен `Project URL` мен `anon public` кілтін көшіріп алыңыз.
4. (Міндетті емес) **Authentication → Sign In / Providers → Email** бөлімінде «Confirm email» опциясын өшірсеңіз, қатысушылар поштаны растамай-ақ бірден кіре алады.

### 2. Компьютерде
```bash
npm install
cp .env.example .env      # .env файлына 3-қадамдағы кілттерді жазыңыз
npm run dev               # http://localhost:5173
```

### 3. Өзіңізді зерттеуші ету
Сайтта тіркеліңіз, содан кейін Supabase SQL Editor-да:
```sql
update public.profiles set role = 'researcher'
where id = (select id from auth.users where email = 'сіздің@поштаңыз');
```
Сайтқа қайта кірсеңіз, мәзірде «Эксперимент деректері» бөлімі пайда болады.

### 4. Vercel
Vercel → жоба → **Settings → Environment Variables**: `VITE_SUPABASE_URL` және `VITE_SUPABASE_ANON_KEY` қосыңыз, сосын **Redeploy** жасаңыз.
Supabase → **Authentication → URL Configuration** бөліміндегі `Site URL` өрісіне Vercel мекенжайыңызды жазыңыз.

## Эксперимент топтары
Қатысушыларға тіркелгенде енгізетін топ кодын беріңіз, мысалы `EXP-1` (эксперимент) және `CTRL-1` (бақылау).
Зерттеуші бетінде топтарды бөлек сүзіп, салыстыра аласыз.

## Маңызды ескерту
`src/data/assessment.js` — диагностика құралы. Оны **эксперимент басталғанға дейін** ғылыми жетекшімен келісіңіз.
Эксперимент кезінде өзгертуге болмайды, әйтпесе pre мен post нәтижелерін салыстыру мүмкін болмайды.
